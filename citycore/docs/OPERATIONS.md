# Запуск, диагностика и обслуживание

## Порядок процессов

1. MariaDB.
2. Миграции (`npm run db:migrate`).
3. NestJS API (`npm start` или контейнерный профиль backend).
4. RAGE MP server.
5. Клиент RAGE MP / GTA V.

Для остановки локального API нажми Ctrl+C в его терминале. Для Docker: `docker compose stop`. Именованный том сохраняет данные. `docker compose down -v` удалит базу, поэтому не используй его как обычную команду остановки.

## Частые ошибки

| Симптом | Проверка |
|---|---|
| `npm` не найден | Установлен ли Node 22+, перезапущен ли терминал |
| PowerShell запрещает npm.ps1 | Используй `npm.cmd` или Command Prompt |
| `ECONNREFUSED 127.0.0.1:3306/3307` | Работает ли MariaDB, совпадает ли DB_PORT |
| `Access denied for user` | DB_USER/DB_PASSWORD и хост в CREATE USER; TCP подключение идёт к 127.0.0.1 |
| `Unknown database` | Созданы ли citycore и citycore_test |
| Таблица не существует | Выполни миграции перед API |
| `EADDRINUSE :3100` | Уже работает второй API; останови один процесс |
| `Доступ запрещён` в игре | BRIDGE_KEY в .env совпадает с packages/citycore/server-config.json |
| `Configure ...` | Запусти setup; сгенерированные ключи не должны быть заменены шаблонным текстом |
| Нет меню | Установлен client_packages/index.js, загружен citycore, нет ошибок в серверной/клиентской консоли |
| Нет фургона | Проверь spawn-координаты, enable-nodejs и ошибки RAGE; повтори смену |
| «Подойдите к нужной точке» | Правильное место и dimension=0; точки показаны на карте |
| «Нужен служебный транспорт» | Игрок сидит в своём выданном фургоне, двигатель/машина не уничтожены |
| UI в браузере не выполняет действия | Это намеренный предпросмотр; игровые события существуют в CEF RAGE |
| `TEST_DB_NAME ending in _test` | Укажи отдельную тестовую БД, например citycore_test |
| `Слишком много запросов` | Подожди 10 секунд; для входа/регистрации лимит 8 попыток/минуту на IP |
| Redis не подключается | Проверь Redis и REDIS_URL, либо оставь URL пустым для одного API-процесса |

## MariaDB

Поддерживаются MariaDB 10.11+ / InnoDB и utf8mb4. Приложение использует запросы Knex через mysql2. Схема не рассчитывает на PostgreSQL или SQLite. Время хранится в BIGINT как Unix milliseconds; деньги — целые игровые доллары.

Миграции защищены стандартным lock-механизмом Knex. DDL в MariaDB автоматически коммитится: если первоначальная миграция оборвалась, прежде чем повторять, проверь таблицы и `knex_migrations`. В новой пустой демо-базе можно восстановить чистую базу; в базе с данными сначала сделай резервную копию и разбери причину. Автоматического сброса данных в проекте нет.

Интеграционные тесты создают аккаунты с уникальными именами в `TEST_DB_NAME`; существующие строки не удаляют. Нагрузочный тест создаёт 20 дополнительных персонажей и не очищает их. Не используй эту БД как рабочую.

## Docker

`compose.yaml` публикует MariaDB и API только на loopback. Скрипт начального создания `citycore_test` выполняется один раз на пустом томе. Если том уже существовал до добавления скрипта, создай тестовую БД и выдачу прав вручную.

Значения `MARIADB_DATABASE` и `MARIADB_USER` в compose фиксированы как `citycore`; соответствующие DB_NAME/DB_USER в .env должны совпадать. Изменение пароля в .env не меняет пароль уже созданного пользователя в существующем томе: его надо изменить SQL-командой под администратором.

Контейнерный API по умолчанию использует локальный ограничитель. Чтобы подключить Redis, измени его `REDIS_URL` в `compose.yaml` на `redis://redis:6379`, запусти оба профиля `backend` и `extras`, затем пересоздай контейнер API. При недоступности Redis запросы не продолжаются без лимитов; операция возвращает ошибку сервиса.

## Linux

Те же npm-команды выполняются из каталога проекта под обычным пользователем. Для постоянной работы можно использовать systemd с отдельным пользователем и WorkingDirectory проекта, ExecStart системного Node на `dist/src/main.js`, Restart=on-failure. RAGE server — отдельная служба с собственной рабочей папкой. Не копируй приватную конфигурацию в клиентские пакеты.

Подключение с другого ПК касается игровых портов RAGE, а не API или БД. По официальной документации по умолчанию это UDP 22005 и HTTP-порт раздачи пакетов 22006; для локальной демонстрации проброс на роутере не требуется: <https://wiki.rage.mp/wiki/Getting_Started_with_Server>.

## Резервные копии

Делай дамп своей рабочей базы средствами MariaDB/HeidiSQL. Сохраняй отдельно `.env` и серверную конфигурацию в безопасном месте. Перед обновлением кода останавливай игровые записи и проверяй миграции на копии данных. Политика очистки ledger/item_log/operations в демо не реализована: удаление квитанций сокращает период защиты от повторного запроса.
