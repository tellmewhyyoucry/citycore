**CityCore RP** — проект для портфолио разработчика игровых систем на платформе RAGE MP. Объединяет несколько связанных механик: игрок выполняет доставки, получает зарплату, совершает банковские операции, покупает и передаёт предметы.

**Возможности**

* Регистрация и авторизация с хешированием паролей.
* Курьерская работа: служебный транспорт, маршруты, доставка заказов, зарплата, опыт и уровни.
* Банковская система: наличные, счёт, пополнение, снятие, переводы и история операций.
* Инвентарь: слоты, ограничения веса, стопки предметов, использование и передача другим игрокам.
* Магазин с покупкой и продажей предметов.
* Сохранение персонажа, баланса и инвентаря в MariaDB.
* Игровые интерфейсы на Vue 3 через CEF.
* Административный API для просмотра состояния экономики и журналов операций.

**Техническая реализация**

Игровая логика выделена в отдельное ядро на TypeScript и NestJS. Серверный адаптер RAGE MP связывает её с игровыми событиями, транспортом и интерфейсом.

Денежные операции и передача предметов выполняются в транзакциях MariaDB. Блокировки строк защищают от конкурентного изменения балансов и дублирования предметов. Повторные запросы обрабатываются без повторного выполнения успешно завершённой операции.

**Стек:** TypeScript, Node.js, NestJS, RAGE MP API, MariaDB, Knex, mysql2, Vue 3, Vite, Docker Compose. Redis поддерживается как опциональный ограничитель частоты запросов.

**Проверки**

Пройдены 23 автоматических теста, включая интеграционные проверки на MariaDB. Локальный нагрузочный прогон выполнил 1000 переводов без ошибок с сохранением итоговых балансов. Этот замер относится к операциям ядра и базы данных, а не к количеству одновременно подключённых игроков.

В репозитории предусмотрены миграции, инструкции запуска, конфигурация CI и сценарий демонстрации проекта.

**Статус:** версия для локальной демонстрации и дальнейшего развития. Полный игровой прогон в GTA V требуется выполнить отдельно. Проект не связан с Majestic RP и не использует его исходный код.
